# サンプル集

このフォルダには、実際の運用で使われているスキル・エージェント・フックの設計パターンを収録しています。
**そのままでは動きません**。自分の業務に合わせてカスタマイズして `.claude/` に配置してください。

## 使い方

1. 参考にしたいサンプルを読む
2. 自分の業務に合わせて内容を書き換える
3. `.claude/skills/` や `.claude/agents/` にコピーする

## サンプル一覧

### エージェント（agents/）
| ファイル | パターン | 学べること |
|---------|---------|-----------|
| `secretary.md` | 秘書エージェント | 複数スキルの統合・ブリーフィング出力設計 |
| `analyst.md` | 分析エージェント | KPI軸での判断基準の埋め込み方 |

### スキル（skills/）
| ファイル | パターン | 学べること |
|---------|---------|-----------|
| `morning-briefing/` | 朝ブリーフィング | カレンダー + タスクの統合スキル設計 |
| `next-action/` | ネクストアクション | 議事録からのタスク自動抽出パターン |
| `mtg-pipeline/` | 議事録パイプライン | 複数ステップ順次実行の設計パターン |
| `task-done/` | タスク完了管理 | ファイル間連携（tasks.md → completed）の簡潔な例 |
| `gform/` | Googleフォーム作成 | 広告運用では通常不要だが、アンケート・申込フォーム作成に使える |

### フック（hooks/）
| ファイル | パターン | 学べること |
|---------|---------|-----------|
| `slack-notify.py` | Stop hook | Claudeの応答をSlackに転送するパターン |
| `notification-slack.py` | Notification hook | 入力待ち/権限確認をSlack通知するパターン |
