# ===== サンプル: ネクストアクション整理スキル =====
# 参考パターン: カレンダー議事録からのタスク自動抽出
name: next-action
description: "「ネクスト」「次のタスク」「何すればいい」と言ったときに発動。議事録・カレンダーからネクストアクションを抽出して整理する。"
---

## 処理フロー

1. Google Calendarから直近7日の予定を取得
2. 各予定に紐づく議事録（Google Docs）を特定
3. 議事録からアクションアイテム（「TODO」「要対応」「次回までに」等）を抽出
4. 担当者・期限付きでリスト化
5. 既に完了済みのものは除外

## 出力フォーマット

```
## ネクストアクション一覧

### 直近7日のMTGから抽出
| MTG名 | アクション | 担当 | 期限 |
|-------|-----------|------|------|
| 〇〇定例 | △△を確認 | 自分 | 4/10 |

### 既存タスクで未完了のもの
- タスク名（期限: MM/DD）
```

## ポイント

- 議事録が存在しない予定はスキップする
- 重複するアクションは統合する
- 期限が過ぎているものは警告表示する
