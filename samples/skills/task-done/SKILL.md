# ===== サンプル: タスク完了管理スキル =====
# 参考パターン: ファイル間連携（tasks.md → completed_tasks.md）
name: task-done
description: "「〇〇終わった」「〇〇完了」「〇〇できた」と言ったときに発動。タスク一覧から該当タスクを完了済みに移動する。"
---

## 処理フロー

1. ユーザーの発言からタスク名を特定
2. タスク管理ファイル（`tasks.md`）を読む
3. 該当タスクを `[ ]` → `[x]` に変更
4. 完了日時を追記
5. 完了済みタスクログ（`completed_tasks.md`）に記録を追加

## タスクファイルのフォーマット例

### tasks.md
```markdown
## 未完了タスク

- [ ] 週次レポート作成（期限: 4/10）
- [ ] 新規施策の企画書ドラフト（期限: 4/12）
- [x] MTG議事録の整理（完了: 4/8）
```

### completed_tasks.md
```markdown
## 完了済みタスク

| タスク名 | 完了日 | 備考 |
|---------|--------|------|
| MTG議事録の整理 | 2026-04-08 | — |
```

## マッチングロジック

- 完全一致でなくても部分一致で候補を表示する
- 候補が複数ある場合は「どのタスクですか？」と確認する
- 該当なしの場合は「該当するタスクが見つかりません」と報告
