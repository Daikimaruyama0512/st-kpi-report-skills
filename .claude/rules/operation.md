## 開発・運用ガイドライン

### 1. 開発ツールの統一
- **Claude Code への集約**: すべてのAIによる開発支援は Claude Code に集約する。他ツールとの分散を避け、共有の「スキル（MDファイル）」を最大限活用する
- **VS Code 拡張機能の利用**: VS Code 上で Claude Code を動作させることで、ファイル構成の動的把握と、ファイルの読み書き・実行プロセスの明視化を行う

### 2. 意思決定のプロセス（計画 → 確認 → 実行）
- **計画の事前提示**: 複雑な変更やコスト（GCPクエリ・外部API呼び出し等）が発生する操作の前に、必ず実装計画を提案し、人間の承認を得てから実行する
- **破壊的操作の前に確認**: ファイル削除・git force push・DB操作・本番環境への変更など、取り消しが困難な操作は必ず事前に確認を取る
- **検証の徹底**: 変更後は必ず動作を確認し、結果を分かりやすくレポートする

### 3. パッケージ・外部スクリプトの安全性
- インストールするパッケージは、信頼できるソース（PyPI, npm 公式など）から取得し、バージョンを固定（`requirements.txt` / `package.json`）すること
- GitHubの未確認スクリプトや非公式パッケージの実行は禁止
- `curl | bash` や `wget` によるスクリプト直接実行は禁止。必ず内容を確認してから実行する

### 4. 環境の原則
- 複雑な本番環境の構築を除き、Python や Node.js のホスト環境（仮想環境）で直接開発を行う
- 開発環境の構築に迷ったらユーザーに確認する
