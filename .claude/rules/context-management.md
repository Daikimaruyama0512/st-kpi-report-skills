## コンテキスト管理ルール

### /compact のタイミング
- コンテキスト使用率が **50%を超えたら** `/compact` を促す
- 複雑なタスク（議事録処理・KPI分析・コード生成）の開始前に使用率が高い場合は先に compact を提案する

### plan mode の活用
- 複数ファイルにまたがる修正、新しいスキル・エージェントの設計、仕様が曖昧な依頼は plan mode から始める
- 「とりあえず作って」でも、影響範囲が広い場合は plan mode を提案する

### セッション設計
- 1セッションで扱うトピックは1〜2つに絞る
- 大きく異なるタスクを同一セッションで連続して行わない（コンテキスト汚染を防ぐ）
