## このスキルの流れ

1. **STEP 1**: 対象月・本数をユーザーに確認（未指定の場合）
2. **STEP 2**: 必須11ファイルをすべて読み込む
3. **STEP 3**: 対象月の季節変数を抽出する
4. **STEP 4**: セグメント割合に応じてシナリオ本数を配分する
5. **STEP 5**: PASONAフォーマットでシナリオを出力する
6. **STEP 6**: マーケティング品質チェック（16項目）を行う
7. **STEP 7**: コンプライアンスチェック（12項目）を行い、NGゼロを確認してから最終出力する

---

## STEP 1: 確認事項

以下が未指定の場合はユーザーに聞く。

- **対象月**: 何月用のシナリオか
- **本数**: 何本か（デフォルト5本）
- **修正の場合**: 既存シナリオのテキストを貼ってもらう
- **LP種別**（任意）: 「ペルソナLPタイパ」「ペルソナLP単願」と指定があればSTEP 5のCTA分岐に反映する

## STEP 3: 対象月の季節変数を抽出する

**`knowledge/creative/monthly_seasonal_variables.md` を開き、対象月のセクション（例: `## 6月`）を参照する。**
以下7変数を作業メモに転記してから STEP 4 へ進む。**1変数でも確認を飛ばさない。**

| 確認する変数 | monthly_seasonal_variables.md の対応項目 | 使い道 |
|---|---|---|
| **需要スコア・出稿強度** | 需要スコア | 出稿判断・全体トーン |
| **心理フェーズ** | 心理フェーズ | P（Problem）要素の設計 |
| **大学イベント・行事** | 大学イベント・行事 | **フックの具体シーン**（「テスト後」「学祭が終わって」等）← 冒頭0.5秒のシーン設定に直接使う |
| **シナリオ活用ポイント** | シナリオ活用ポイント | イベントをどのフックパターンに当てはめるかの指針 |
| **塾業界の動向** | 塾業界動向 | N（Narrow down）の緊急性根拠 |
| **求職者メリット** | 求職者メリット | O（Offer）要素 |
| **知覚変化ゴール** | 知覚変化ゴール | シナリオ全体のゴール設定 |
| **フックアイデア（3本）** | フックアイデア | 冒頭フックをここから選ぶ or 大学イベントと組み合わせて派生させる |
| **推奨CTA** | 推奨CTA | A（Action）要素 |
| **セグメント割合目安** | セグメント割合目安 | STEP 4の本数配分に直接使う |
| **月別NG表現・注意事項** | 月別NG表現・注意事項 | STEP 6チェックに持ち越す |

> **大学イベントをフックに使う際の鉄則（`monthly_seasonal_variables.md` 末尾の補足表も参照）:**
> - イベントは「具体的なシーン設定」として使う（例:「テストが終わった日に」「学祭の準備で忙しいけど」）
> - イベント自体を否定・批判する表現はNG（「テストばっかりで疲れた人へ」などネガティブな共感狙いは暗い印象）
> - そのイベントが終わっている月/まだ始まっていない月には使わない（時期外れはリアリティがなく刺さらない）

> ※ `creative_trend_insights.md` の「今月の季節変数」セクションも併せて確認し、最新のBigQueryデータと齟齬がないかチェックする。

## STEP 4: 本数配分の決め方

**STEP 3で転記した「セグメント割合目安」を使って按分する。**

例：6月に5本作成 → タイパ35% / 単願35% / 併願30%
- タイパ向け：2本
- 単願向け：2本
- 併願向け：1本

例：7月に5本作成 → タイパ50% / 単願30% / 併願20%
- タイパ向け：3本（比率が最も高い繁忙期）
- 単願向け：1〜2本
- 併願向け：0〜1本

各セグメントにつき、顕在層と潜在層を混ぜる（全部顕在にしない）。
LP種別の指定（ペルソナLPタイパ/単願）がある場合は指定を優先してセグメント割合を上書きしてよい。

## STEP 5: シナリオ出力フォーマット

各シナリオを以下の形式で出力する。本文は**PASONAの各要素をテーブルで分けて**出力する。

```
### シナリオ①「タイトル」
**ターゲット：** ペルソナ名（例：タイパ顕在 / 単願潜在）
**フックパターン：** 常識の否定 / 見えない損失の可視化 / 情報の非対称性 のいずれか
**CTA：** 以下の分岐で決定する

**【ペルソナLPタイパ指定時】** 遷移先: https://sb2.juku.st/match

| # | CTA文言 | 使う文脈 |
|---|---|---|
| A | 「LINEで自分に合う塾、探してみて」 | 顕在層・情報の非対称性フック・探索意欲が高い |
| B | 「LINEで診断してみて。1分でできるから」 | 潜在層・見えない損失フック・行動コストを下げたい |

**【ペルソナLP単願指定時】** 遷移先: https://sb2.juku.st/search

| # | CTA文言 | 使う文脈 |
|---|---|---|
| A | 「LINE登録しておくだけでスカウトが届くから、やってみて」 | 潜在層・受動的・「おまかせ」に響く |
| B | 「スカウト待つだけだから、登録してみて」 | 顕在層・安心感訴求・O（不安解消）が主軸 |
| C | 「まずLINEだけ追加してみて」 | 潜在層・常識の否定フック・行動ハードルを最低にしたい |

**【指定なし（デフォルト）】**

| ペルソナLP（推奨） / ブランド診断 / 気軽に診断 のいずれか ※実績ではペルソナLPが最良（CPA 7,595円・CVR 3.5%） |
|---|

**選定根拠：** 月の季節変数・セグメント割合・creative_trend_insights.mdの傾向を踏まえて1行で

| PASONA要素 | 内容 |
|---|---|
| **P（Problem）** | ターゲットが抱えている問題・痛みを描写する文（冒頭0.5秒フック含む） |
| **A（Affinity）** | 「わかるよ、その気持ち」と共感・親近感を示す文 |
| **S（Solution）** | 塾講師ステーションが提供する解決策を提示する文 |
| **O（Offer）** | 具体的なメリット・条件・数字を示す文（週〇コマ・時給〇円等） |
| **N（Narrow down）** | 今すぐ行動すべき理由・緊急性・限定性を示す文 |
| **A（Action）** | CTAを含む行動を促す一文 |

**字数：〇〇字**（P〜A全体を通し文に換算した合計字数）
```

最後に全シナリオの構成まとめ表を出力する。

```
| # | タイトル | ターゲット | フックパターン | 月のインサイト | CTA |
|---|---|---|---|---|---|
```

---

## シナリオ字数・尺のルール

| 項目 | 基準 |
|---|---|
| **字数（目標）** | **151〜200字** |
| **字数（上限）** | 250字（これを超えるとCVRが低下傾向） |
| **動画尺** | 15〜25秒 |
| **根拠** | BigQuery直近90日分析（2026-06-06）：151〜200字帯がCPA 10,297円・CVR 2.68%で最良（12件・CV 386件）。旧目標300〜340字帯はCPA 15,589円・CVR 1.74%と逆効果だった |

> ⚠️ **旧目標（300〜340字）は廃止**。字数が多いほど動画が長くなり視聴維持率が落ちる傾向が確認された。**端的に核心だけ書く**こと。

シナリオ本文を出力したら末尾に字数を必ず明記する。上限250字を超えている場合は削ってから出す。

## STEP 6: マーケティング品質チェック

> コンプライアンス観点（誠実性・業界信頼・炎上リスク）のチェックは STEP 7 で実施する。ここではCVR・ペルソナ適合の観点のみ確認する。

以下を全部確認してから出力する。NGがあれば修正してから出す。

| # | チェック項目 |
|---|---|
| 1 | ターゲットは「タイパ」「単願」「併願」のどれか明示されているか |
| 2 | 「顕在」「潜在」どちらかが明示されているか |
| 3 | 構成が「共感→不安解消→行動促進」の順になっているか |
| 4 | 冒頭0.5秒以内に「塾バイト」と認識できる文言が入っているか |
| 5 | フックが「理想追及」か「損失回避」か、どちらか明確か |
| 6 | 大学生のその月のカレンダー（行事・心理）に合った内容か |
| 7 | 「今やる理由（緊急性・納得感）」が入っているか |
| 8 | メリットの表現が具体的か（「高時給」より「週3コマで月5万円」） |
| 9 | **タイパ向けに「やりがい」訴求をしていないか** ← NG |
| 10 | **単願向けに「稼げる」「タイパ」訴求をしていないか** ← NG |
| 11 | 他バイトを貶める表現がないか |
| 12 | 直接的な学歴訴求（「Fランでも〜」等）がないか |
| 13 | **シナリオ本文が151〜200字に収まっているか（上限250字）** |
| 14 | **【実績反映】LP種別指定がある場合、シナリオの文脈（顕在/潜在・フックパターン）に合ったCTA候補が選ばれているか。選定根拠を1行で明示しているか。指定なしの場合はペルソナLPを優先しているか** |
| 15 | **【実績反映】タイパ系シナリオが最低1本含まれているか（CPA最良セグメント）** |
| 16 | **【実績反映】字幕表示テキストは1カットあたり端的か（詰め込みすぎていないか）** |
| 17 | **【6月以降禁止】「GW明け」「GWは診断」などGW関連フックが使われていないか（賞味期限切れ）** |
| 18 | **【直近勝ちパターン確認】「情報の非対称性」フック（隠れ急募・穴場・知っている人だけ得）がタイパ向けに1本以上含まれているか（直近CVR最高9.52%）** |
| 19 | **【前半離脱防止】冒頭フックの直後（P〜A要素）に「具体的な価値・シーン」が続いているか。フックで終わらず即座に中身に入ること（エンゲージメント分析：前半離脱パターンがCPA最悪20,193円）** |
| 20 | **【CVRドライブ】シナリオ中盤（S〜O要素）に「自分ごと化できる具体シーン・数字」が入っているか。3秒再生率はCPAを分けない——CVR差（4.1% vs 1.3%）が成否を決める** |

## NG訴求・表現一覧

| NG | 理由 |
|---|---|
| タイパ向けに「やりがい」「先生と呼ばれる」 | タイパはコスパ・効率で判断。情緒訴求は刺さらない |
| 単願向けに「稼げる」「タイパ」「高時給」 | 単願は安心感・フィット感重視。お金訴求はNG |
| 「稼げる」だけの汎用フック | 塾以外のバイト広告と区別できない |
| 他バイト（飲食・コンビニ等）を直接貶める | ブランド棄損リスク |
| 「Fランでも〜」など学歴訴求 | ユーザー心理に反する |
| 保護者対応への言及 | 不安を煽るだけで逆効果 |
| **「ブラックな塾」「ブラックに当たる」** | 業界・運営企業全体への不信感を助長。No.6抵触 |
| **「ほとんどの人が妥協して選んでる」等の根拠なき統計的断定** | 競合サービスや一般求職方法を間接的に批判する表現。No.9抵触 |
| **「かなりの機会損失」「リスクがある状態」等の強煽り** | 過度に追い詰めるトーン。No.12抵触。「〜の可能性もある」に緩和する |
| **「最適な塾が出てくる」「リスクはゼロ」等の絶対保証** | サービス実態と乖離した過大表現。No.2抵触。「条件に合う塾を絞り込める」「気軽に試せる」に置き換える |
| **「GW明けから」「GWは診断」などGW関連フック** | 直近の使用済みフック。6月以降は賞味期限切れ（2026年6月〜禁止） |

> ※ 業界信頼・法的リスクに関わる表現（保護者対応・他職業毀損・学歴表現・運営企業批判等）は **STEP 7 コンプライアンスチェック** でも重複確認する。

## STEP 7: コンプライアンスチェック（出力前・必須）

STEP 6のマーケティング品質チェック通過後、以下12項目のコンプライアンス自己評価を行う。
**1件でもNGがあれば、必ず修正してから最終出力する。NGゼロを確認してから出力すること。**

### 評価手順

1. 全シナリオに対して12項目を順番に評価する
2. 結果を以下のJSON形式で自己出力する（スプレッドシートのGemini APIチェックと同形式）
3. `"判定": "NG"` が1件でもあれば、`"理由"` を参照してシナリオを修正し、STEP 7を再実行する
4. 全項目OKになったら `全項目OK` と一言添えて最終出力に進む

### JSON出力フォーマット

```json
{
  "Overall Assessment": "OK：全12項目に抵触なし",
  "Non-compliant Items": [],
  "コメント": "ガイドラインに基づき、品質チェックが完了しました。"
}
```

NGがある場合：

```json
{
  "Overall Assessment": "NG：[理由を1行で]",
  "Non-compliant Items": [
    {
      "No": "5",
      "ガイドライン種別": "業界リーダー - 講師質低下表現",
      "判定": "NG",
      "理由": "職業の専門性を不当に矮小化する表現が含まれている",
      "該当箇所": "「座ってるだけで月5万稼げる」"
    }
  ],
  "コメント": "上記箇所を修正してSTEP 7を再実行してください。"
}
```

### チェック12項目

| # | カテゴリ | チェック項目 | NGとなる表現例 | OKの方向性 |
|---|---|---|---|---|
| 1 | 誠実性 | **数値表現の一貫性** | 同一シナリオ内で書類通過率などの数値に揺れ・矛盾がある | 算出根拠がある数値のみ使用する |
| 2 | 誠実性 | **提供内容の誤解防止** | 「面談不要」「全教室の口コミが見れる」「必ずスカウトが来る」「最適な塾が出てくる」「リスクはゼロ」等、実際のサービスと乖離した断定・絶対保証表現 | 事実に基づいた表現・「条件に合う塾を絞り込める」「気軽に試せる」等の正確な表現 |
| 3 | 業界リーダー | **塾社員ネガティブ表現** | 「保護者対応ってめんどい」「雑務だらけ」「指導報告書って非効率」等、現場社員の職務を否定する主観的表現 | 「保護者対応って緊張する」等、心理的状態・事実ベースの表現 |
| 4 | 業界リーダー | **保護者不安表現** | 「保護者対応やりたくない」「生徒の質問対応がめんどくさい」等、保護者に不信感を与える表現 | 「指導にもっと集中したい」等、向上心にフォーカスした表現 |
| 5 | 業界リーダー | **講師質低下表現** | 「Fランでも余裕で受かる」「座ってるだけで稼げる」「誰でもできる」「お小遣い稼ぎに最適」等、職業の専門性を不当に矮小化する表現 | 「研修がしっかりしてるから初心者でも受かる」等、客観的根拠を添えた表現 |
| 6 | 業界リーダー | **運営企業・業界への不信感助長** | 「騙される」「搾取」「ブラック」「ブラックな塾に当たる」「低い時給に騙されるな」等、運営企業や業界全体を悪意あるものとして描写する表現 | 「職場の雰囲気が事前にわかる」等、ユーザーが安心して選べる情報提供の表現 |
| 7 | 業界リーダー | **他職業毀損** | 「単純作業な仕事より」「報われない仕事」「ブラックバイトから脱却」等、他職種・他バイトを不当に否定する表現 | 塾バイトのメリットを直接的に訴求する（他と比較しない） |
| 8 | 業界リーダー | **特定塾・ブランド毀損** | 特定の塾名を名指しした批判、「集団指導は残業が多め」等の特定指導形態への一方的な否定 | 「個別指導は〜な特徴がある」等の中立的な説明 |
| 9 | 業界リーダー | **総合サイトとの根拠なき比較** | 「ありきたりな情報しかない」「ただの求人サイト」「ほとんどの人が妥協して選んでる」「求人サイトを何個も開いても時間だけ過ぎる」等、根拠なく競合他社や一般求職方法を批判・断定する表現 | 「情報が多くて絞り込むのに時間がかかる」等、ユーザー自身の体験・行動視点の表現 |
| 10 | 業界リーダー | **学習塾ロゴ・商標の無断使用** | 他社学習塾の企業ロゴ・アイコン・商標の無断使用指定（テキストシナリオで映像素材を指定している場合） | 使用する場合は営業確認済みであることを明記する |
| 11 | 誠実性 | **転職難易度の誤認** | 「誰でも簡単に成功できる」「努力しなくても年収が上がる」「1分で最適な塾が見つかる」等、過度な期待・ゼロ努力で完結するかのような表現 | 「1分で条件を入力するだけで候補を絞り込める」等、機能の説明として正確な表現 |
