# 大学生インサイト（STターゲット深掘り）

最終更新: 2026-04-26（customer_info_st.md / sns_ads_scenario_master.md / who_what_how.md / 塾ブランド別偏差値スプレッドシート より集約）

※CA版の「03_面談サマリー.md」に相当するST版。大学生へのインタビューや行動データ・口コミ分析から抽出した心理・行動パターンをまとめる。

## 1. ターゲット層の分類

| セグメント | 悩み・インサイト | 特徴 |
|---|---|---|
| **タイパ重視層（効率追求）** | 手っ取り早く条件の良いバイトを見つけたい。無駄な検索に時間を使いたくない | 効率性を最優先。自分の学力を活かせる・就活で語れる環境を求める |
| **ミスマッチ回避層：単願型（慎重派）** | ブラックだったらどうしよう。自分に教えられるか不安 | 心理的な安心感を重視。口コミや内部情報からフィット感を確認したい |
| **ミスマッチ回避層：併願型（比較検討派）** | 飲食と塾、どっちが自分に合っているか分からない | 複数の選択肢を比較し、納得してから動く。診断・ランキング系コンテンツに反応する |

## 2. 登録・応募動機TOP5

口コミ偏差値スコア（10次元分析）とユーザーの実際の声から導出。

1. **シフト融通（最重要）**: 「大学の授業と両立できるか不安。テスト期間は休みたい」
   → 口コミ実例: 「試験期間にはレギュラーのシフトを休めたりと、とても柔軟に対応してくれる」「テスト勉強、就職活動、帰省などが比較的しやすい」（偏差値10軸中・最高スコア次元）
2. **ミスマッチ回避（職場の雰囲気）**: 「ブラックな塾には行きたくない。事前に内情が分かれば安心」
   → 口コミ実例: 「アットホームな雰囲気で、先生同士の仲も良く楽しく働けている」「上司や社員の方が優しく話しかけてくれる」
3. **受験経験の換金**: 「大学受験で勉強した知識を活かしてお金にしたい」（特に新1年生）
4. **就活資産（ガクチカ）**: 「塾講師のバイトはプレゼン力・言語化能力が身につくと聞いた」
   → 口コミ実例: 「教える力、わかりやすく説明する力、コミュニケーション能力が向上した」「プレゼン力・将来的にも役立つ」
5. **タイパ・高時給**: 「同じ時間を使うなら、稼げて就活にも役立つ方がいい」
   → 口コミ実例: 「事務時給などもでてしっかりしている」「1分単位で残業代が出る」

## 3. 共通ペインポイント

口コミのネガティブ分析・タグ分類から導出した実際の不安・疑問。

| ペインカテゴリ | 具体的な不安・疑問 | 口コミ実例（ネガティブ面） |
|---|---|---|
| **給与の不透明性** | 「事務給（授業外の作業代）はあるの？」「実質時給はいくら？」「コマ給と時給どっちがお得？」 | 「授業準備や採点の時間が無給になることがある」「事務給がない塾もあるので要確認」 |
| **シフト・学業との両立** | 「テスト期間は休める？」「大学が忙しい時期でも働けるの？」 | 「急なシフトイン打診があり断りにくい」「学業優先を理解してもらいにくい教室もある」 |
| **未経験への不安** | 「教えたことないけど大丈夫？」「研修・サポートはある？」 | 「研修がマニュアル任せで不安だった」「新人サポートが手薄な教室がある」 |
| **職場のミスマッチ** | 「社員・先輩との関係はどう？」「ノルマはある？」「ブラック塾かどうか分からない」 | 「教室長の連絡が遅く（数日後に返信）コミュニケーションに困った」「入社前のイメージと現場が違った」 |
| **通勤・勤務地** | 「家や大学から近い塾を効率よく探したい」 | — |

## 4. 時期別の心理フェーズ

常に刺さる万能メッセージは存在しない。大学生のカレンダーに合わせて訴求を切り替えることが最強の勝ち筋。

| 時期 | 心理フェーズ | ユーザー心理 | 有効な訴求軸 |
|---|---|---|---|
| **11月** | **実利期** | コスパよく稼ぎたい・冬期講習でガッツリ稼ぎたい | タイパ・高時給・事務給の確認 |
| **12月** | **防衛期** | シビアな実利確認・損しないか確認 | 事務給が出るか・年末にいくら稼げるか |
| **1月** | **逃避期** | テスト勉強の合間に気軽にバイト検索 | 「テスト勉強の合間に気軽に診断」「3分でできる診断」 |
| **2〜3月** | **焦燥期** | 受験経験の換金・優良枠が埋まる前に動かなければ | 新1年生向け「受験知識を活かす」・「春に向けて今動くべき」 |
| **3〜4月** | **新生活期** | 新大学1年生の初バイト探し・今が最も動きやすい | 「大学生活スタートダッシュ」「1年生の今が一番条件が良い」 |
| **7〜8月** | **繁忙期** | 夏期講習でガッツリ稼ぐ・夏休みに新しいことを始めたい | 「夏期講習で稼ぐ」「夏に向けて今から登録」 |
| **9月** | **新学期期** | 2学期に向けて安定した収入源が欲しい | 「2学期から始める」「秋から塾講師を始めると就活に間に合う」 |

## 5. ターゲット層別のゴール設計（CTA）

ターゲットの特性に応じて、広告の着地点（CTA）を使い分ける。

| ターゲット層 | リードタイム | 導線設計 |
|---|---|---|
| **超・即決層**（新1年生など） | 約51分で応募に至る | ペルソナLP → 直応募。即決できる情報を最初から提供 |
| **中長期ナーチャリング層**（既存大学生など） | 14日〜最大40日 | 「気軽に診断」でリスト仕込み → LINE育成 → 条件に合った求人をレコメンドして刈り取り |

## 6. マーケティング示唆

### 最大の差別化訴求
> **「口コミ15万件があるから、ブラック塾を事前に避けられる。一般求人サイトには聞けない塾の内情、正直に教えます」**

これがSTの最大の価値。「ミスマッチ回避」という大学生の根本的な不安に直接刺さる。

### 生々しいインサイトの活用
- 「事務給」「授業外作業」「コマ給と時給の違い」→ 知っているだけで得する情報として訴求
- 「飲食 vs 塾」「単純作業 vs 塾講師」→ 対比構造で「座って稼げる」優位性を見せる
- 「先生と呼ばれる」「生徒から感謝される」→ 承認欲求・やりがいを情緒的価値として訴求

### インサイト合致でCPM高騰を抑制できる
繁忙期はCPMが高騰するが、大学生特有の心理（インサイト）に合致した動画シナリオであれば抑制できる。
時期に合わせた文脈変更（損失回避 vs 理想追求）がクリエイティブPDCAの最重要変数。

## 7. 塾ブランド口コミ分析（偏差値10軸）

> データソース: スプレッドシート `19N9E6lvaK6qKds6fw8mlPHCt-lT_IzV71L4Q8c87ZZ4`（ブランド別偏差値タブ）  
> 分析手法: 口コミテキストをEmbedding/ベクトル化し、10の評価軸について偏差値スコアを算出

### 10の評価軸（ユーザーが塾バイトを選ぶ判断基準）

| # | 評価軸 | 内容 | 広告示唆 |
|---|---|---|---|
| 1 | **アットホーム** | 職場の雰囲気・人間関係の温かさ | 「居心地の良い職場か」の不安に直接対応 |
| 2 | **上司が優しい** | 教室長・社員のサポート姿勢 | 「厳しく叱られないか」という未経験者の不安を払拭 |
| 3 | **ホワイトな労働環境** | 事務給・残業代・コンプライアンス遵守 | 「サービス残業がないか」「事務給はあるか」の透明性訴求に直結 |
| 4 | **シフトの柔軟性** | 学業・就活・テスト期間に合わせたシフト調整 | **全10軸中で最重要**。大学生の最大関心事 |
| 5 | **研修が親切丁寧** | 入社時・継続的な指導サポートの充実度 | 未経験者の「教えられるか不安」を解消 |
| 6 | **スキルがつく** | コミュニケーション力・プレゼン力・説明力の習得 | 就活資産（ガクチカ）訴求の根拠 |
| 7 | **個別の裁量が大きい** | 授業設計・指導方針の自由度 | 「自分らしく働きたい」層に刺さる |
| 8 | **生徒との関わりが深い** | やりがい・達成感・感謝される体験 | 情緒的価値（承認欲求）訴求の根拠 |
| 9 | **清潔な教室** | 設備・教室環境の快適さ | 衛生環境を重視する層に訴求 |
| 10 | **活気がある** | 活発な職場・モチベーション維持のしやすさ | エネルギッシュな職場を求める層に訴求 |

### 代表口コミ（高評価軸）

**シフト柔軟性（最高スコア）**
> 「試験期間にはレギュラーのシフトを休めたりと、とても柔軟に対応してくれる」  
> 「テスト勉強、就職活動、帰省などが比較的しやすい」

**ホワイト労働環境（事務給・残業代）**
> 「事務時給などもでてしっかりしている」  
> 「1分単位で残業代が出る」

**スキル習得（就活価値）**
> 「教える力、わかりやすく説明する力、コミュニケーション能力が向上した」  
> 「プレゼン力・将来的にも役立つスキルが身に付く」

**やりがい（生徒との関わり）**
> 「生徒と喜びを分かち合えることに塾講師のやりがいを感じます」  
> 「成績が上がった時に感謝された時が最も嬉しかった」

**アットホームな職場**
> 「アットホームな雰囲気で、先生同士の仲も良く楽しく働けている」  
> 「上司や社員の方が優しく話しかけてくれる環境」

### ネガティブ口コミ要約（「避けるべき塾」の特徴）

> ※ 口コミ分析サマリータブより抽出。入社前のミスマッチ防止に活用。

| ネガティブパターン | 代表的な口コミ内容 |
|---|---|
| **連絡・コミュニケーション不全** | 「教室長からの連絡が数日後になることがあり困った」「質問しても返答が遅い」 |
| **急なシフト変更・強制感** | 「急にシフトイン打診があり断りにくい雰囲気だった」 |
| **入社前後のギャップ** | 「説明と実際の業務内容が違った」「研修が不十分で現場に出された」 |
| **事務給なし・サービス残業** | 「授業準備や採点が無給の場合があった」「規定外の業務を求められた」 |

## 8. 職場タイプ分類タグ（塾バイト選びの判断軸）

口コミから抽出した13種の職場タイプタグ。ブランド診断・シナリオ設計に活用。

| タグ | 特徴・刺さるターゲット |
|---|---|
| **アットホーム・和気あいあい** | 人間関係重視層。「居心地の良い職場で働きたい」 |
| **風通しが良く相談しやすい** | 不安を抱えた未経験者・内向的な学生 |
| **活気がある・明るい** | エネルギッシュな環境を求める社交的な学生 |
| **落ち着いた・真面目** | 集中して仕事したい・騒がしい環境が苦手な学生 |
| **メリハリがある** | オンオフのメリハリを求めるタイパ重視層 |
| **研修・サポートが手厚い** | 未経験・教えることへの不安が強い層 |
| **規律・ルール重視** | 組織的な環境を求める・しっかりした塾で働きたい学生 |
| **学業・プライベート優先** | 大学の授業やサークルを最優先にしたい学生 |
| **実力・成果主義** | ガクチカにしたい・評価されて成長したい意欲的な学生 |
| **ホワイトな労働環境** | 事務給・残業代の透明性を重視する慎重派 |
| **自主性・裁量重視** | 自分で考えて授業設計したい・クリエイティブ志向 |
| **ビジネスライク・ドライ** | 割り切って稼ぎたい・必要以上の関わりを求めない学生 |
| **やりがい・生徒との絆** | 教えること・感謝されることに価値を見出す学生 |
