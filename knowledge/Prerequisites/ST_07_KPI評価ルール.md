# ST事業 KPIダッシュボード・評価ルール

最終更新: 2026-04-26（business-overview.md / 07_KPI評価ルール.md（CA版）参考 / bigquery-schema.md より集約）

---

## 目的

Meta広告のタイムラグを正しく考慮した「真の応募CPA評価」ができる報告体制を構築する。
週次（速報）と月次（本評価）を分離し、短期的な数字に振り回されない判断基準を持つ。

---

## なぜこのルールが必要か

「気軽に診断」経由の潜在層は、LINE登録から応募まで14〜40日のタイムラグがある。
毎週の定例直前に施策を変えると「当月の応募CPAが悪化」して見えてしまう構造的問題がある。

**核心原則**: 「施策の評価」と「速報の数字チェック」を分離する。

- **週次（速報）**: LINE登録数・応募数の速度感チェックのみ → 施策判断に使わない
- **月次（累計）**: 直近90日累計の応募CPA・CPFで本評価

---

## ダッシュボード設計（3セクション）

### Section 1: KPIサマリーカード（直近90日累計）
- 累計広告費 / 累計LINE登録（CPF）/ 累計応募数 / 応募CPA
- 一目で目標達成・未達がわかるカード形式

### Section 2: CTA別パフォーマンス表（直近90日累計）
| 行（CTA種別）| 気軽に診断 / 塾ブランド診断 / ペルソナLP / 新1年生向け / SNS ORG |
|---|---|
| **列** | 累計広告費 / 累計LINE登録 / 累計応募数 / 転換率 / CPF / 応募CPA / 評価 |

### Section 3: グラフ2本
1. **月次応募数（積み上げ棒グラフ）**: CTA別の貢献量をひと目で
2. **応募CPA トレンド折れ線**: 速報（オレンジ点線）vs 累計（ネイビー太線）vs 目標（グレー破線）

## 評価サイクル・運用ルール

| 評価の種類 | 頻度 | 対象指標 | 判断基準 | 担当 |
|---|---|---|---|---|
| **速度チェック（参考）** | 週次 | 当月速報：LINE登録数・応募数 | ±30%変動でアラート | 学S・運用担当 |
| **ROI評価（本評価）** | 月次 | 累計90日：応募CPA・転換率 | 目標1.3倍超で要見直し | 運用担当＋レビュアー |
| **予算配分見直し** | 四半期 | CTA別累計CPA | Q末累計値で次Q予算決定 | レビュアー承認 |
| **クリエイティブ廃止判断** | 随時 | 単クリエイティブのCPA | 消化¥15,000超でCV0 → 停止 | 運用担当即断 |

**NG**: 単週の応募数が少ないからといって施策を即中止しない（タイムラグの可能性）

## タイムラグ参考値（CTA別）

| CTA | 登録→応募 タイムラグ |
|---|---|
| **ペルソナLP（顕在・直応募）** | 約51分（即決型）|
| **新1年生向け** | 数日〜1週間程度 |
| **塾ブランド診断（顕在）** | 数日〜2週間程度 |
| **気軽に診断（潜在）** | 14日〜最大40日（ナーチャリング必要）|

直近2週間以内のCTAからの応募CVは過小評価されている可能性がある。  
特に「気軽に診断」は、登録数が多い月の40日後に応募が増える構造を理解して評価する。

## 本評価の判断基準

### 応募CPA
| 状態 | 基準 | 対応 |
|---|---|---|
| **良好** | 応募CPA ≤ ¥20,000 | 継続。予算引き上げを検討 |
| **要観察** | ¥20,001〜¥30,000 | 原因を特定。クリエイティブ・LPの改善を検討 |
| **要見直し** | ¥30,001〜¥40,000 | CTA配分・ナーチャリング改善を優先対応 |
| **要停止検討** | ¥40,001以上 | 施策レベルで見直し。継続理由を明確化できなければ停止 |

### 転換率（LINE登録→応募）
| 状態 | 基準 | 対応 |
|---|---|---|
| **良好** | 転換率 ≥ 15% | 継続。LINE育成施策の効果あり |
| **要改善** | 10〜14% | LINEシナリオ・リッチメニューの改善を優先 |
| **要緊急対応** | < 10% | LINE育成の根本的な見直し |

### CPF（LINE登録単価）
| 状態 | 基準 |
|---|---|
| **顕在層（ペルソナLP等）** | ¥1,500〜¥3,000 が目安 |
| **潜在層（気軽に診断等）** | ¥700〜¥1,500 が目安 |

---

## クリエイティブ単体の停止・維持判断

| 判断軸 | 基準 |
|---|---|
| **消化金額とCV** | 消化¥15,000（日予算×約2日）超でCV0件 → 即停止 |
| **CPA高騰** | 直近2日のCPAが目標1.5倍超でも、直近4日が1.5倍以下なら様子見 |
| **初期消化不良** | 出稿2日経過で消化¥1,000未満 → 停止 |
| **ターゲット外CV** | 25歳以上・エリア外のCV比率が20%超 → 訴求見直しを検討 |

## BigQuery での確認方法

詳細は `knowledge/bigquery-schema.md` を参照。

```sql
-- STの直近90日 CTA別応募CPA集計（CTEパターン必須）
WITH base AS (
  SELECT
    ad_name,
    SUM(spend) AS spend,
    SUM(purchase) AS purchase,
    SAFE_DIVIDE(SUM(spend), NULLIF(SUM(purchase), 0)) AS cpa
  FROM `bigquery-jukust.dataset.v_ST_meta_ads_daily_report`
  WHERE date >= DATE_SUB(CURRENT_DATE(), INTERVAL 90 DAY)
  GROUP BY ad_name
)
SELECT * FROM base
WHERE spend >= 10000
ORDER BY cpa ASC
```
