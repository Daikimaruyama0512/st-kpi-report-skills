# CA・ST 事業概要

## 塾講師ステーションキャリア（CA事業）

塾業界特化の正社員向け転職エージェント兼求人媒体。

| 項目 | 内容 |
|---|---|
| サービス正式名 | 塾講師ステーションキャリア |
| 事業種別 | 転職エージェント + 求人媒体（ハイブリッド） |
| ターゲット | 20〜30代・初めて塾業界への転職を検討する人（未経験者含む） |
| 最重要KPI | エージェント申し込み数（年間700件目標） |
| 広告費合計 | 年間3,290万円 |
| 広告費内訳 | LINE広告 2,530万円 / 顕在層 760万円 |
| 部門売上目標 | 1億1,500万円 / 入社目標 年間30件 |

### ファネル構造

```
Meta広告クリック / Google広告クリック
  → LP 表示
  → LINE登録（FV: ファーストビューCV）
  → 面談申込（エージェント申し込み） ← 最重要KPI
  → 面談実施
  → 求人応募
  → 採用
```

### タイムラグ（重要）

Meta広告ではFV登録から面談申込までにラグがある。評価時は必ず考慮すること。

| チャネル | FV登録→面談申込 タイムラグ |
|---|---|
| Google / P-MAX | 約1日（即決型） |
| Meta FV相談 | 約2日 |
| Meta FV登録 | **中央値40日**（ナーチャリング必要） |

直近40日以内のCV数は過小評価されている可能性がある。

### KPI評価サイクル

| 頻度 | 確認内容 | 重みづけ |
|---|---|---|
| 週次 | LINE登録数・相談数の速度感 | **参考のみ** |
| 月次 | 直近90日累計 面談単価・採用単価 | **本評価** |
| 四半期 | 予算配分の見直し | 意思決定 |

### チャネル別年間目標

| チャネル | エージェント申込 | 面談単価 | 年間広告費 |
|---|---|---|---|
| LINE広告 | 524件 | ¥87,942 | ¥25.3M |
| 顕在層広告（Google等） | 114件 | ¥95,307 | ¥7.6M |
| サイト直接流入 | 62件 | ¥81,501 | — |
| **合計** | **700件** | — | **¥32.9M** |

### 現在の運用ルール

- **ASC廃止（2026年3月〜）**: 一般COP運用のみ。ASCは設定しない
- **ターゲティング**: 45歳以上・エリア外ユーザーは手動除外済み。設定変更不要
- **予算超過ルール**: 月間広告費が10%以上超過する見込みになったら、事前承認フォームで申請してから変更する

## 塾講師ステーション（ST事業）

塾業界特化の求人サイト（アルバイト・正社員）。

| 項目 | 内容 |
|---|---|
| サービス正式名 | 塾講師ステーション |
| 事業種別 | 求人サイト（メディア型） |
| ターゲット | 塾講師・家庭教師として働きたい人（学生〜社会人） |
| KPI | Meta広告経由の応募数またはLINE登録数 |

### CA事業との違い

| 比較軸 | CA（キャリア） | ST（ステーション） |
|---|---|---|
| ターゲット | 正社員転職希望者 | アルバイト・家庭教師希望者 |
| ビジネスモデル | 採用課金（エージェント） | 掲載課金（求人媒体） |
| SNSトーン | 転職不安解消・実績訴求 | 情報提供型（CTAなし） |
| シナリオ仕様 | 300文字以内・40-50秒 | 300文字以内・40-50秒（同じ） |

## FY26 最重要目標

**ユニットエコノミクス改善**（2026-04-06 猪瀬MTGで確定）

3本柱:
1. **顕在層獲得**: 対象外ユーザーではなく意欲・条件合致者を連れてくる
2. **スクリーニング改善**: 面談転換率を向上させる
3. **SNS・オーガニック開拓**: 広告費95%依存からの脱却

前年度の反省: LINE登録・申込数は目標達成したが面談単価が高く、転換率が低い「三角状態」を改善する。
