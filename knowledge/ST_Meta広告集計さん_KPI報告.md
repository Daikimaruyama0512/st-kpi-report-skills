### kpi-report スキルのデータフロー（v2: 集計さん分離後）

```
BigQuery
  ├── CR別90日集計（spend≥1万円）→ CR別セクション
  ├── 週次・月次集計（当週/前週/月累積）→ LINE登録CV / COST / CPC / CTR / CVR / CPM
  └── CTA別月次集計（ad_nameパース）→ CTA別 LINE登録CV / COST / 応募CV

ST_KPI報告「入力」タブ（軽量・数行のみ）
  └── 月間予算 / LINE登録CV目標 / 応募CV（custom_cv_2がなければ手動）

↓ 書き込み先

ST_KPI報告（1xXeCl4...）
  ├── ST_KPI報告 タブ: 行15/26/27/35/45-58
  └── KPI報告 のコピー タブ: P30/T30/X30/AB30/P32/T32
```
