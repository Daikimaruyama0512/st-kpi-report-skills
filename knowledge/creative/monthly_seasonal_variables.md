# 月別季節変数マスタ（ST Meta広告 シナリオ作成用）

シナリオ作成時、**対象月のセクションだけを読んで**全変数を確認する。
ソース: ST_05_大学生カレンダー.md / customer_info_st.md / creative_trend_insights.md / BigQuery直近分析

> **読み方**: create-scenario SKILL の STEP 3 で「対象月」が確定したら、このファイルの該当月セクションを開き、
> 全変数をそのまま作業メモに転記してから STEP 4 へ進む。
> **大学イベント・行事** と **シナリオ活用ポイント** は フック設計（STEP 5のP要素）に直接使う。

## 1月

|---|---|
| **需要スコア** | ★★★（3/5）出稿強度: △ 維持（テスト期で反応鈍い） |
| **心理フェーズ** | 逃避期 — 共通テスト・大学期末テスト期間中。勉強の合間に現実逃避としてスマホを見る |

| **シナリオ活用ポイント** | 「試験期間中の逃避タイミング」を逆手に取る。「テスト勉強の合間に」「試験が終わったら」というシーン設定で低ハードルの診断誘導が有効。就活との掛け合わせ（「ガクチカになる塾バイト」）は3年生ターゲットに刺さる |
| **塾業界動向** | 大学入試期間で塾側の採用も一時停滞。ただし春の繁忙期（3〜4月）に向けた採用準備が静かに始まっている |

| **知覚変化ゴール** | 「今は忙しくても登録だけしておけば、3月に稼ぎ始めた人に差をつけられる」と気づかせる |

## 補足: セグメント割合の使い方

STEP 4「本数配分の決め方」でこの割合を使って按分する。

例: 12月に5本作成 → タイパ40% / 単願35% / 併願25%
- タイパ向け: 2本
- 単願向け: 2本
- 併願向け: 1本

> **注意**: セグメント割合はあくまでも目安。LP種別の指定（ペルソナLPタイパ/単願）がある場合は指定を優先する。

## 補足: 大学イベントをフックに使う際の注意

| 使っていいフック素材 | 使ってはいけないフック素材 |
|---|---|
| テスト前後の「切り替えタイミング」 | 「テストで大変な人へ」（共感狙いだが暗い印象） |

| 「内定が出たら余裕で塾バイトを」（3〜4年生限定） | 高校受験中の受験生ターゲット訴求 |
