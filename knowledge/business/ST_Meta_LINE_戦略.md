# 1. エグゼクティブサマリー（結論4行）

> 数値はすべて週次タブ（`ST_Meta広告集計さん`）の月次実績で `応募CPA = CPF ÷ 転換率` を検算済み（第2-3章）。転換率＝「全体応募CV ÷ Meta登録」（週次タブ定義）。

1. **直近の悪化要因は転換率ではなくCPF**。応募CPAは4月¥10,011→5月¥18,967へ悪化したが、**転換率は20.1%→20.4%でむしろ横ばい。悪化はCPFが¥2,016→¥3,870へ1.9倍に跳ねたことが主因**（恒等式で完全に検算一致）。→ **最優先レバーはCPF（登録効率の回復）**。
2. **CPF高騰の正体は「登録CVR（クリック→登録率）の低下」＋CPM上昇。CTRではない**。`CPF = CPC ÷ 登録CVR`、`CPC = CPM÷(CTR×1000)`。登録CVRは**年初20.9%→5月8.3%へ一貫して半減**し、CPMも¥500→¥878へ上昇。CTRは0.26→0.27%で安定。**クリックは取れているのに登録に至っていない**＝LPO（登録ページ/診断）が直撃する領域。
3. **転換率（登録→応募）は約20%で天井**。年初は転換率改善（5.4%→20%）が応募CPAを押し下げたが、もう伸びしろは小さい。応募CPA¥18,967を分解すると悪化要因は①登録CVR-28%（最大）②CPM+22%③CTR-13%で、**転換率の寄与はゼロ**。
4. **最優先はLPO（登録CVR回復）**。"打ち手の引き出しが空"＝①LPO（ゼロ）②フォーマット（UGC一辺倒）③CTA出し分け④権威の数字⑤CRMセグメント配信。中でも**登録CVRを年初水準に戻すのが最も効く**（後述の感度分析）。

> **今すぐ（6月）の5手**: ①気軽に診断LP/診断のLPO→登録CVR回復【最優先・最大要因】 ②未投入フォーマット（静止画・漫画・ビジネス風）でCTR維持＋摩耗対策 ③登録CVR・CPM・CPFを週次で指標分解監視 ④跳ねたシナリオの月別出し分けルール化 ⑤CRMセグメント配信の実装着手（転換率の天井破り・補助）

# 2. 中核ロジック（指標で分け切る → 要因特定 → 感度分析）

## 2-1. KPIロジックツリー（応募CV/CPAを指標で分け切る）★このツリーが起点

```
【数量ツリー】 応募CV を分解（どう増やすか）
応募CV（目標 1,651件/月）
├─ 転換率（登録→応募） 20.4%  ○天井・従
└─ 登録
   ├─ 登録CVR（クリック→登録） 8.3%  ★★★最優先（年初20.9%→半減）
   └─ CT（クリック）
      ├─ CTR（クリック率） 0.27%  ◎安定・守り
      └─ IMP（露出）  予算×CPMの従属

【単価ツリー】 応募CPA を分解（どう安くするか）
応募CPA  ¥18,967（→ 目標¥14,273以下）
├─ 転換率  20.4%  ○天井・従
└─ CPF（登録単価）  ¥3,870  ★
   ├─ 登録CVR  8.3%  ★★★最優先

```

**葉指標＝ IMP / CTR / 登録CVR / 転換率 ＋ 配信単価CPM**（CPC・CPFは中間ノード）。
**優先度（感度分析2-4準拠）＝ 登録CVR ≫ CPM > CTR維持 > 転換率**。各葉のWHY/HOWは第6章（5W1H）へ。

## 2-3. 悪化の要因分解（指標ツリー・どの指標が動いたか）

**CPFが4倍化（¥907→¥3,870、1→5月）を乗法分解**：
```
CPF ×4.3
├ CPC ×1.7   ┬ CPM ×1.76（配信単価上昇＝外部要因・競合/オークション）
│            └ CTR ×0.96（ほぼ不変。むしろ微改善）
└ 登録CVR ÷2.5（20.9%→8.3%）★最大要因 ＝ クリック後に登録しない
```
**直近4→5月の応募CPA悪化（¥10,011→¥18,967）も：登録CVR -28%（最大）＋CPM +22%＋CTR -13%。転換率の寄与はゼロ。**

> 結論：**応募CPA悪化の主犯は「登録CVR（クリック→登録率）の構造的低下」**。CTRは安定＝フックは効いている。問題は**クリックした人が登録ページ/診断で離脱している**こと（LPO未着手が直撃）＋配信単価CPM上昇（外部）。

> **登録CVRを年初水準に戻すのが圧倒的に効く（¥18,967→¥7,843）**。これがLPOを最優先にする数値的根拠。CPMは外部要因で打ち手限定。CTR・転換率は既に良好で伸びしろ小。

**仮説（★★）**: Meta広告からの流入の多くはInstagram/Facebookアプリ内蔵の「アプリ内ブラウザ」経由。アプリ内ブラウザはOSの制限で外部アプリへのディープリンク遷移がブロックされやすく、この中間画面の「アプリで開く」が無反応に見えるケースが起きやすい。クリックは発生している（CTR安定）のに登録に至らない（登録CVR年初20.9%→8.3%）という本章の指摘と構造的に整合する。

**検証方法（未実施）**: 実機のInstagram/Facebookアプリ内蔵ブラウザから実際にこの導線を踏み、「アプリで開く」が反応するか確認する。反応しないケースが多ければ、LP側でアプリ内ブラウザを検知して直接Chrome起動を促す、または「ブラウザでログインする」をデフォルト動線にするなどの技術対処を検討する。

# 8. 岩﨑の2つの課題感への論点整理（SIM R80-81）

### 論点① なぜMetaでなくYTに750万投資するのか
- 慎重材料（★★★）: YTは過去CPA¥25,000でMetaの約10倍（2026-03-23アフィニティMTG）。アプリYTは一時停止実績あり。
- 論理（★★）: Metaは新年度でCPFが2倍＝獲得効率が天井に近い。新規リーチ面としてYTに一定の合理性。
- **推奨**: YTは「リーチ拡大の実験枠（少額×検証）」に留め、**先にMetaの未探索（フォーマット×LPO）を潰す方が投資対効果が高い**。YT本格投下はMeta探索の結果を見てから。

### 論点② Appの転換率15.7%はMetaでも通用するか／潜在層獲得はやめるべきか
- ⚠️ **まず定義統一が必要**: Meta転換率は定義で激変する（①週次=登録→応募 約20% ②line_crm_v3=残存友だち比 4.05% ③SIM広告のみ 8.97%）。App「インストール→応募」15.7%がどの段階かを揃えないと比較不能。
- 事実（★★）: Meta「登録→応募」(週次定義)は約20%で、**App前提15.7%を上回る**。"Appだから転換率が高い"という前提は、Metaの実績20%を見ると自明ではない。App増額の根拠が「高転換率」なら**要再検証**。
- 一方（★★）: 残存友だち比(line_crm_v3)ではMetaルート4.05%と低い＝即日ブロック・離脱が多い。**Metaの弱点は"登録後の定着・刈り取り"**（CRM領域）であって、登録→応募の率そのものではない。
- 潜在層をやめるべきか（★★）: 完全には切らない。潜在はCPFが安く量の源泉。ただし「間口を広げると残友比CVRは下がる」のは**データ上Yes**（気軽に診断2.4%）。→ **潜在は"育成前提"でCRM(v3)とセット**運用。顕在CTA比率を引き上げて定着を底上げ。

# 9. 戦略ナラティブ（戦略・戦術として語る）

**戦略（どこで勝つか）**: 指標で分解すると、応募CPA悪化の主犯は**登録CVR（クリック→登録率）の構造的低下**（年初20.9%→5月8.3%）。CTR（フック）は安定、転換率（登録→応募）は20%で天井。つまり**勝負どころは「クリックした人を登録まで運ぶ」＝LPO（登録ページ/診断の最適化）**。ここがゼロのまま放置されている。CPM上昇は外部要因で打ち手限定。CRMは`v3`で役割分担済み。広告チームは**登録CVRの回復に最優先で集中**する。

**戦術（何をどの順でやるか）**:
1. **LPO（登録CVR回復）を最優先**（6月）: 気軽に診断LP/診断のFV・コピー・設問数をA/B。広告↔LP↔初回シナリオの期待値を一致。登録CVRを年初水準20%へ（感度分析で応募CPA¥7,843の最大効果）。
2. **フォーマット多様化でCTRを"守る"**（従）: 静止画・漫画・ビジネス風でUGC一辺倒の摩耗リスクを潰す。CTRは攻めではなく守り。
3. **登録CVR・CPM・CPFを週次で指標分解監視**: どの指標が動いたかを毎週特定。摩耗CR即停止。
4. **転換率は維持＋CRMで微増**（従）: セグメント配信・即日BL対策で20%→+数pt。
5. **YT/Appは検証枠**: YTは少額実験、Appは高転換率前提の妥当性を実データで検証してから増額。

**北極星KPI**: LINE応募CV（月次）。**最重要ボトルネック指標＝登録CVR（クリック→登録、5月8.3%→年初20%へ回復）**。次にCPM、CTRは維持、転換率は20%維持。

# 10. 何が問題で、もっとやることは何か（結論）

**現状の問題（一言で）**: STのMeta広告は「フック開発」は進んだが、**"テキスト動画×3分診断"の単一フォーマット・単一CTAに閉じている**。CAが当たり前にやっている多フォーマット・CTA出し分け・権威の数字・物語UGCを試してすらいない。だから「成果が悪い」のではなく「打ち手の引き出しが空のまま戦っている」。

**もっとやることリスト（○×の❌を全部やる・優先度順）**
1. ❌→⭕ **LPO着手（気軽に診断LP/診断）＝登録CVR回復【最優先・最大効果】** 設問数削減・FV/コピーA/B・広告↔LPの期待値一致
2. ❌→⭕ CTAの出し分け（量=診断／質=求人直・相談）＝登録CVRと転換率の両取り
3. ❌→⭕ 静止画CR投入（条件数字・企業ロゴ）＝CTR守り＋最速・最安の空白埋め
4. ❌→⭕ 主人公物語UGC（CAのBefore/After型をST大学生版に翻訳）
5. ❌→⭕ 権威の数字を全CRに（口コミ15万件・20年）
6. ❌→⭕ 跳ねないCRの予算停止（CTR<0.2は即停止。¥119万浪費の根絶）
7. ❌→⭕ 時期×勝ちフックの出し分けカレンダー化（7-2章をルール化）
8. ❌→⭕ LINE CRMセグメント配信・Day7刈り取り・新着push（v3の❌を実装＝転換率の天井破り）
9. ❌→⭕ 登録CVR・CPM・CPFを週次で指標分解監視（どの指標が動いたか毎週特定）

> **最優先は登録CVR（クリック→登録率）の回復＝LPO**（1〜2）。感度分析で最も効く（応募CPA¥18,967→¥7,843）。CTR（3〜6）は安定だが守りとして多様化。転換率（8）は天井のため従。**現状は「クリックは取れるのに登録で落としている」。LP/診断という"受け皿"を直すのが次の一手**。
