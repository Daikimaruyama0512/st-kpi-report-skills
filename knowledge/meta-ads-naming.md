# Meta広告 命名規則マスタ

## 命名フォーマット

```
[フェーズ][メディアタイプ]_[訴求軸][動画の型][検証箇所][パターン]_[出稿日]
```

例: `NV_E070002_260209`
→ 新規(N)動画(V)・潜在層向け(E)・インタビューUGC風(07)・オリジナル(00)・パターン2・2026/02/09出稿

---

## フェーズ（1文字目）

| 記号 | 意味 |
|---|---|
| `N` | 新規制作 |
| `E` | 横展開（既存素材を流用） |

---

## メディアタイプ（2文字目）

| 記号 | 意味 |
|---|---|
| `V` | 動画 |
| `P` | 静止画 |
| `M` | 背景が動く静止画 |

### フォーマット組み合わせ例

| プレフィックス | 意味 |
|---|---|
| `NV_` | 新規制作の動画広告 |
| `EV_` | 横展開の動画広告 |
| `NP_` | 新規制作の静止画広告 |
| `EP_` | 横展開の静止画広告 |
| `NM_` | 新規制作の背景動く静止画 |
| `EM_` | 横展開の背景動く静止画 |

**旧命名規則（参考）:**
- `FM` / `V_` / `CA_` は旧フォーマット。2025年以前の広告名に使われている

---

## 訴求軸（3文字目）

| 記号 | 意味 | 想定ターゲット |
|---|---|---|
| `A` | 安心 | 転職を不安に感じている層 |
| `B` | 承認 | 自己肯定感を高めたい層 |
| `C` | 自己実現 | キャリアアップを目指す層 |
| `D` | 所属 | 塾業界コミュニティへの帰属感 |
| `E` | 潜在層向け | まだ転職を具体的に考えていない層 |
| `F` | 企業PUSH | 優良求人企業の訴求 |
| `G` | 潜在層向け_3分診断 | 「3分でわかる適職診断」CTA |
| `H` | 潜在層向け_年収診断 | 「年収診断」CTA |
| `I` | プロ講師_3分診断 | プロ講師向け・3分診断CTA |

## 動画の型（4〜5文字目）

| 記号 | 意味 | 特徴 |
|---|---|---|
| `01` | UGC | ユーザー生成コンテンツ風 |
| `02` | インタビュー | 対談・インタビュー形式 |
| `03` | 中の人 | 担当者・社員が話す |
| `04` | ビジネスライク | 企業・採用担当向けトーン |
| `05` | アニメ | アニメーション・イラスト |
| `06` | UGC-しぬ | UGC風の強い引きフック |
| `07` | インタビューソースのUGC風 | インタビュー素材をUGC風に編集 |
| `08` | インタビューソースの漫画 | インタビュー素材を漫画風に編集 |

---

## 検証箇所・パターン（6〜9文字目）

- **検証箇所（6〜7文字目）**: `00`=オリジナル、`01`=フック変更、`02`=CTA変更、`07`=摩耗防止、など
- **パターン（8文字目）**: `0`〜`9`（同じ設定の複数バリエーション）

---

## 出稿日（10〜15文字目）

`YYMMDD` 形式（例: `260209` = 2026年2月9日）

---

## 命名チェックリスト

クリエイティブ登録・命名時に確認:

- [ ] フェーズ（N=新規 / E=横展開）が企画書と一致している
- [ ] メディアタイプ（V/P/M）が実際のクリエイティブと一致している
- [ ] 訴求軸（A〜I）が企画書のターゲット設定と一致している
- [ ] 動画の型（01〜08）が制作フォーマットと一致している
- [ ] 出稿日が `YYMMDD` 形式になっている
- [ ] 同日・同設定のバリエーションはパターン番号で区別している

---

## 分析時の注意

- **プレフィックスの自己解釈禁止**: `NV_` を "Narrative Video" などと勝手に解釈しない。このマスタ準拠で読む
- **旧命名規則の扱い**: 2025年以前の `FM` / `V_` / `CA_` 広告は旧フォーマット。シナリオNULLの場合はプレフィックスから推定し「推定:」と明記する
- **NULLシナリオでも分析を止めない**: データなしではなく、プレフィックス推定でフォーマット分類を継続する
