# ST事業 競合利用調査

最終更新: 2026-04-26（customer_info_st.md・既存ナレッジより集約）

> ※ CA版「04_競合利用調査.md」に相当するST版。
> 大学生の他サービス利用傾向・STを選んだ理由・競合への不満を整理する。
> 実データが不足している箇所は「推定:」と明記。

---

## 1. 他サービス並行利用の傾向

推定: 大学生の多くは複数の求人サービスを並行利用する傾向がある。

| 利用パターン | 傾向 |
|---|---|
| **Indeed + タウンワーク + 塾ステ** | 最も多いと思われる3サービス並行利用。Indeed・タウンワークで一般条件を確認した後、塾ステで口コミ・詳細情報を確認する |
| **塾ステ単独** | 塾講師バイトに絞って探しているユーザー。既に「塾講師一択」と決めている顕在層 |
| **塾講師JAPAN + 塾ステ** | 教育特化求人サイトを複数比較するユーザー |
| **Instagram経由→塾ステ** | 広告・SNSオーガニック経由で初めて塾ステを知り、そのまま登録に至るケース |

推定: Meta広告経由の潜在層は「塾ステを最初に見た」ケースが多く、他サービスとの比較を経ずに登録することも多い。

---

## 2. STを選んだ理由（推定・仮説ベース）

| 選択理由 | 詳細 |
|---|---|
| **口コミの豊富さ** | 「職場の雰囲気が事前にわかる」「ブラック塾を避けられる」という信頼感。15万件の口コミは他サービスにない強み |
| **塾専門への安心感** | 「塾に特化しているから情報が詳しい」「塾の事情をわかってくれている」という専門性への信頼 |
| **診断コンテンツ** | 「塾ブランド診断」「適職診断」など、ゲーム感覚で使えるコンテンツが登録の入口になるケース |
| **Instagram広告経由** | UGC動画で「自分に関係ある内容だった」「こんなバイトあるんだ」と知って登録 |
| **友人・先輩の口コミ** | 推定: 大学内での口コミ（紹介）が一定数存在する可能性 |

---

## 3. 競合への不満（推定・仮説ベース）

| 競合の不満 | 内容 |
|---|---|
| **Indeed・タウンワーク** | 「塾以外の求人が混ざって探しにくい」「職場の内情が全くわからない」「条件だけで判断するしかない」 |
| **塾講師JAPAN** | 推定: 「口コミが少ない・古い」「診断コンテンツがない」 |
| **家庭教師派遣会社** | 「個別案件で選択肢が少ない」「エリアが限られる」「自分でシフト管理しにくい」 |
| **一般エージェント型** | 「面談が面倒くさい」「メールや電話が多い」→ STのセルフサービス型はこの不満を解消できる |

---

## 4. 最も獲得しやすい層（推定）

優先度順に整理：

| 優先度 | 層の特徴 |
|---|---|
| **高** | **新大学1年生（3〜4月）**: 塾講師バイトを初めて探す。受験経験を活かしたい。「先輩に教えてもらった」感覚で動ける |
| **高** | **他バイトから乗り換え検討層**: 「飲食や単純作業に疲れた」「もっと学力を活かしたい」と感じている既存大学生 |
| **中** | **テスト勉強中の逃避層（1月・6月）**: バイト探しを先延ばしにしているが、診断コンテンツで「気軽に試せる」なら動く |
| **中** | **繁忙期（夏期・冬期講習）前の準備層**: 「稼ぎたい季節が来る前に準備しておきたい」層。7〜8月・11〜12月前に仕込む |
| **低** | **すでに他サービスで塾を探している顕在層**: Google検索で塾ステを直接流入するユーザー（Meta広告では取りにくい）|

## 5. 離脱ユーザーの再活性化施策

CA版での「他社で上手くいかなかった人の再獲得」に相当する施策。

推定: 以下のケースで離脱ユーザーが一定数存在する：
- LINE登録はしたが応募に至らなかったユーザー
- 一度応募したが採用に至らなかったユーザー
- バイトを辞めて再度求職中になったユーザー

**再活性化のアプローチ（仮説）**:
- LINE配信での「季節に合わせた求人レコメンド」
- 「あなたにおすすめの塾が見つかりました」プッシュ配信
- GW後・夏前など「また稼ぎたい季節」に合わせたタイミング配信
