## 競合カテゴリ分類

| カテゴリ | 代表例 | 特徴 |
|---|---|---|
| **① 総合求人サイト** | Indeed, タウンワーク, マイナビバイト | 求人量が多い。塾以外の職種も混在。条件検索が主流 |
| **② 教育特化型求人** | 塾講師JAPAN, jukuwork, 家庭教師バイト | 塾・家庭教師に特化するが、口コミ・診断コンテンツが薄い |
| **③ 家庭教師派遣会社** | トライ, 家庭教師のナゴヤ等 | 個別案件マッチング型。ユーザーの手間が少ないが、柔軟性に欠ける |

## 自社優位性（USP）

| 強み | 理由・詳細 |
|---|---|
| **特化性** | 塾講師専門のため「ノイズのなさ」が際立つ。大学生に特化した細かい検索軸（科目・時給・シフト）が利用できる |
| **信頼性** | 15万件以上の口コミデータ。求人票の表面情報だけでなく、教室の「リアルな内情」がわかる |
| **専門性** | 業界20年の知見に基づいた「塾ブランド比較」や診断コンテンツ（塾ブランド診断・適職診断）|
| **コンテンツ力** | 「失敗しない塾選び」「事務給の計算式」など大学生特化の情報発信 |

---

## ポジショニング空白地帯

2×2 マトリクス（横軸: 塾特化↔非特化 / 縦軸: 診断・口コミあり↔なし）

```
              口コミ・診断あり
                    |
  塾ステ ★          |
                    |
  教育特化  --------+-------- 総合求人
  (塾講師JAPAN等)   |          (Indeed等)
                    |
              口コミ・診断なし
```

**自社の空白地帯**: 「塾専門 × 口コミ豊富 × 診断付き × 大学生特化」という組み合わせを持つプレイヤーは競合に存在しない。

## 競合が使えていない訴求軸

| 訴求軸 | 競合の状況 | 自社の優位性 |
|---|---|---|
| **口コミによるミスマッチ回避** | 競合はほぼ求人票のみ。職場の雰囲気・人間関係の情報がない | 15万件口コミで「入社前に職場の内情がわかる」訴求が可能 |
| **事務給・給与の透明性** | 「時給○○円〜」の表示のみ。授業外作業代（事務給）の有無が不明 | 事務給の計算式・実態情報を提供できる（機会損失訴求に活用）|
| **大学生カレンダー連動の緊急性** | 時期に関係なく一律の求人表示 | テスト期・長期休暇・春休みなど「今動くべき理由」を時期に合わせて訴求できる |
| **就活資産としての価値** | 「バイトを探す」という枠組みのみ | 「塾講師 = ガクチカになる」「プレゼン力・就活最強説」という意味的価値を付与できる |

## 競合が取れていない層

| 層 | 特徴 | 自社のアプローチ |
|---|---|---|
| **積極検索をしていない潜在層** | Googleで求人を探していないが、SNSで良い求人があれば動く | Meta広告のUGCで「インサイトを突く」動画を見せてリスト仕込み |
| **慎重派（ミスマッチ怖い層）** | 塾バイトに興味はあるが「ブラックだったらどうしよう」と二の足を踏む | 口コミ・診断コンテンツで不安を払拭。「失敗しない選び方」を訴求 |
| **リプレイス層** | 飲食・単純作業バイトに疲弊し「もっとスキルが身につく仕事がしたい」 | 「座って稼げる」「就活に役立つ」という対比訴求で発見させる |

## 競合分析サマリー

**自社のスローガン（案）**: 「塾講師バイトを探すなら、塾専門・口コミ15万件の塾ステ」

**コアポジション**: 初めて塾講師バイトを探す大学生の「ミスマッチ不安と機会損失不安」を、塾専門の深い知見と口コミデータで同時に解消する唯一のプラットフォーム

### 動画の型の分布と傾向

| 動画の型 | 使用数 | 特徴・向いている訴求 |
|---|---|---|
| **Vlog（ライフスタイル対比）** | 最多 | Before（不満・現状）→ After（理想の生活）の対比で変化を感情的に訴求。「自分もこうなれる」という共感を引き出す |
| **UGC（インタビュー形式）** | 多 | 「普通の人が語る」リアリティが視聴者の信頼を高める。インタビュアーとの会話形式が自然な流れを作る |
| **解説系** | 少 | サービス機能・メリットを直接説明。信頼性は高いがエンタメ性が低く飽きられやすい |

---

### 共通シナリオパターン（感情設計）

ほぼ全ての競合が以下の感情フローで構成されている：

```
1. 現状への共感・不満提示（問題提起）
   「満員電車、上司の顔色、残業...」「求人ありすぎて分からない」

2. 具体的な変化の提示（Before/After）
   「転職したら手取り40万・土日休み・残業なし」
   「週3在宅、前より年収UP、自分らしく働ける」

3. サービスとの出会い（ブリッジ）
   「見つけたのが◯◯だった」「◯◯のLINE追加をして」

4. 行動喚起（CTA）
   「無料診断してみて」「今すぐ登録」「LINE追加するだけ」
```

---

### CTAのトレンド

| CTA形式 | 採用率 | 特徴 |
|---|---|---|
| **無料診断 / 診断してみて** | 高 | ハードルが低く、「気軽に試せる」感を演出。STの「気軽に診断」と同じ思想 |
| **LINE登録 / LINE追加** | 中 | ゼロタレ等が採用。「簡単な質問に答えるだけ」で登録への障壁を下げる |
| **今すぐ無料で / 登録は無料** | 高 | 「無料」を強調することで踏み出しやすくする |
| **直接応募 / 今すぐ転職** | 低 | 即決層向け。顕在層が多い場合に有効 |

---

### STへの示唆（クリエイティブ制作への応用）

| 観点 | 競合の傾向 | STへの応用 |
|---|---|---|
| **Before/After対比** | 転職・就活系で最も多用される構造。「飲食の肉体労働→塾で座って稼ぐ」は強力なBefore/After | 「飲食バイト vs 塾バイト」対比はSTで既に使用中。さらに強化できる |
| **具体的な数字の提示** | 年収・時給・時間の具体数字が信頼性を高める。「手取り40万」「週3日」等 | 「時給○○円」「事務給あり」「週△コマ」の具体数字を冒頭に出す |
| **インタビュー形式の信頼性** | ミイダス・キャリアネクストが活用。「普通の大学生が語る」形式はSTでも有効 | UGC型で「実際に塾講師をしている大学生」のインタビューは高CVRが期待できる |
| **「無料診断」のCTA** | 業界全体のトレンドとして「無料診断」がCTAの主流 | STの「気軽に診断」「塾ブランド診断」はこのトレンドと合致。継続強化 |
| **特定ターゲットへの特化訴求** | 「高卒専門」「栄養士専門」「事務系キラキラ女子」など特化でペルソナが刺さりやすい | 「受験生だった新1年生向け」「飲食バイトから乗り換えたい人向け」など具体的ペルソナに特化したシナリオが有効 |
| **TikTok活用** | 競合はTikTokが最も多い。STはInstagramが主軸 | TikTokへの展開を検討する価値あり（特に新1年生層）|
